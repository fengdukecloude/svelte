```svelte
<!--- copy: false  --->
{#if expression}...{/if}
```

```svelte
<!--- copy: false  --->
{#if expression}...{:else if expression}...{/if}
```

```svelte
<!--- copy: false  --->
{#if expression}...{:else}...{/if}
```

有条件渲染的内容可以包装在 if 块中。

```svelte
{#if answer === 42}
	<p>问题是什么？</p>
{/if}
```

可以使用 `{:else if expression}` 添加额外的条件，可选地以 `{:else}` 子句结束。

```svelte
{#if porridge.temperature > 100}
	<p>太热了！</p>
{:else if 80 > porridge.temperature}
	<p>太冷了！</p>
{:else}
	<p>刚刚好！</p>
{/if}
```

（块不必包装元素，它们也可以包装元素内的文本。）
