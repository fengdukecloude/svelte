# Svelte 文档翻译审核清单

本清单用于人工审核翻译质量，确保每个翻译文件符合标准。

## 使用说明

1. 每翻译完一个文件，使用本清单进行自查
2. 审核人员使用本清单进行复审
3. 所有必查项必须通过，建议项尽量满足
4. 发现问题及时记录并修正

---

## 一、内容准确性 ✓

### 必查项

- [ ] **完整性**: 所有段落都已翻译，没有遗漏
- [ ] **准确性**: 技术概念翻译准确，没有错误理解
- [ ] **一致性**: 与原文意思一致，没有增删改原意
- [ ] **术语**: 专业术语符合术语表规范
- [ ] **上下文**: 翻译符合上下文语境

### 重点检查

- [ ] Runes 相关概念翻译准确（$state, $derived, $effect 等）
- [ ] 响应式（Reactivity）概念表达清晰
- [ ] 生命周期相关术语准确
- [ ] API 名称和用法描述正确

---

## 二、语言流畅性 ✓

### 必查项

- [ ] **自然**: 中文表达自然流畅，符合阅读习惯
- [ ] **简洁**: 语句简洁明了，不冗余
- [ ] **通顺**: 句子之间逻辑连贯
- [ ] **专业**: 使用专业的技术表达

### 建议项

- [ ] 避免直译导致的生硬表达
- [ ] 适当调整语序使其更符合中文习惯
- [ ] 使用恰当的技术文档语气

---

## 三、格式完整性 ✓

### Markdown 格式

- [ ] **Frontmatter**: YAML 格式正确，title 已翻译
- [ ] **标题**: 标题层级正确，内容已翻译
- [ ] **列表**: 列表格式保持，内容已翻译
- [ ] **引用块**: 引用块格式正确，内容已翻译
- [ ] **特殊标记**: `[!NOTE]`, `[!LEGACY]` 等标记格式正确

### 代码块

- [ ] **语言标识**: 代码块语言标识符保持不变（svelte, js, ts 等）
- [ ] **代码内容**: 代码本身未被翻译
- [ ] **代码注释**: JavaScript/TypeScript 注释已翻译
- [ ] **HTML 文本**: HTML 标签中的文本内容已翻译（如按钮文字）
- [ ] **字符串**: 代码中的字符串根据情况翻译（如提示信息）
- [ ] **文件路径**: `<!--- file: ... --->` 注释保持不变

### 内联代码

- [ ] **保持原文**: 所有内联代码保持英文
- [ ] **格式正确**: 反引号包裹正确
- [ ] **周围空格**: 中英文之间有适当空格

## 四、链接和引用 ✓

### 必查项

- [ ] **内部链接**: 路径保持不变，文字已翻译
- [ ] **外部链接**: URL 保持不变，文字已翻译
- [ ] **相对路径**: 文档间引用路径正确
- [ ] **锚点链接**: 页面内锚点链接有效

### 验证方法

- [ ] 点击所有链接确认可访问

---

## 五、标点符号 ✓

### 必查项

- [ ] **中文标点**: 中文语境使用中文标点（，。！？；：）
- [ ] **英文标点**: 代码、专有名词周围使用英文标点或空格
- [ ] **引号**: 中文引号使用正确（"" 或 「」）
- [ ] **省略号**: 中文使用 ……，代码使用 ...

### 常见错误

- [ ] 避免：`Svelte是一个框架.`（缺少空格，使用英文句号）
- [ ] 正确：`Svelte 是一个框架。`
- [ ] 避免：`使用$state创建状态`（代码周围缺少空格）
- [ ] 正确：`使用 \`$state\` 创建状态`

---

## 六、术语一致性 ✓

### 核心术语检查

- [ ] **Rune / 符文**: 首次出现使用"符文（Rune）"，后续使用"符文"
- [ ] **Component / 组件**: 统一使用"组件"
- [ ] **Reactivity / 响应式**: 统一使用"响应式"或"响应性"
- [ ] **Props / 属性**: 统一使用"属性"或"Props"
- [ ] **State / 状态**: 统一使用"状态"
- [ ] **Effect / 副作用**: 统一使用"副作用"或"效果"

### 检查方法

- [ ] 对照术语表检查所有关键术语
- [ ] 同一文档中相同术语翻译一致
- [ ] 与其他已翻译文档保持一致

## 七、代码示例质量 ✓

### 必查项

- [ ] **代码完整**: 代码示例完整，可运行
- [ ] **注释翻译**: 代码注释已翻译且准确
- [ ] **变量名**: 变量名、函数名保持英文
- [ ] **字符串内容**: 提示信息、UI 文本已翻译

### 示例检查

原文：
```svelte
<script>
	// Create reactive state
	let count = $state(0);
</script>

<button onclick={() => count++}>
	Increment
</button>
```

翻译：
```svelte
<script>
	// 创建响应式状态
	let count = $state(0);
</script>

<button onclick={() => count++}>
	增加
</button>
```

- [ ] 注释已翻译
- [ ] 代码逻辑未改变
- [ ] 按钮文字已翻译
- [ ] 变量名保持英文

- 所有必查项通过

- 语言自然流畅

### 良好（80-89 分）
- 所有必查项通过

- 必查项基本通过
- 建议项完成 ≥ 40%

- 必查项未全部通过
