Svelte 提供了各种内置对象的响应式版本，如 [`Map`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map)、[`Set`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set) 和 [`URL`](https://developer.mozilla.org/en-US/docs/Web/API/URL)，它们可以像原生对应物一样使用，以及一些用于处理响应性的额外实用工具。
