---
title: 什么是符文？
---

> [!NOTE] **rune** /ruːn/ _名词_
>
> 用作神秘或魔法符号的字母或标记。

符文（Runes）是你在 `.svelte` 和 `.svelte.js`/`.svelte.ts` 文件中用来控制 Svelte 编译器的符号。如果你把 Svelte 看作一门语言，符文就是语法的一部分——它们是**关键字**。

符文具有 `$` 前缀，看起来像函数：

```js
let message = $state('hello');
```

然而，它们与普通的 JavaScript 函数在重要方面有所不同：

- 你不需要导入它们——它们是语言的一部分
- 它们不是值——你不能将它们赋值给变量或作为参数传递给函数
- 就像 JavaScript 关键字一样，它们只在特定位置有效（如果你把它们放在错误的位置，编译器会帮助你）

> [!LEGACY]
> 符文在 Svelte 5 之前不存在。
